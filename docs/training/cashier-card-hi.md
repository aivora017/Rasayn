# PharmaCare Pro — कैशियर कार्ड (हिंदी)

*काउंटर पर लैमिनेट करके चिपकाएँ। गल्ला सँभालने वाले को यही याद रखना है।*

---

## F-कुंजियाँ — एक नज़र में

| की | क्या होगा | कब इस्तेमाल |
|---|---|---|
| **F1** | नया बिल / स्क्रीन साफ़ | पुराना बिल खत्म, अगला शुरू करना है |
| **F2** | ग्राहक चुनें | खाते वाला ग्राहक हो; नाम लिखकर Enter |
| **F3** | दवा खोजें | प्रोडक्ट सर्च बॉक्स पर फ़ोकस; नाम लिखो |
| **F4** | छूट डालें | इस लाइन पर discount % देना है |
| **F6** | भुगतान विंडो | नकद / UPI / कार्ड चुनना है |
| **F7** | बैच बदलें | FEFO की जगह दूसरी बैच चाहिए |
| **F9** | रसीद प्रिंट | बिल सेव होने के बाद; दोबारा दबाओ तो "Reprint" |
| **F10** | बिल सेव करें | सब लाइन और भुगतान आ गया |
| **Esc** | विंडो बंद / टोस्ट हटाओ | पेमेंट विंडो बंद करनी हो या error हटाना हो |
| **Enter** | चुनो / पक्का करो | ड्रॉपडाउन में दवा या ग्राहक पक्का करना |

> **नियम:** माउस की ज़रूरत नहीं। पूरा बिल कीबोर्ड से बने — यही सबसे तेज़।

## ऊपर की 5 दिक़्क़तें — और उनका हल

**दिक़्क़त १: बिल सेव नहीं हो रहा**
→ क्या F10 दबाया? नहीं → **F10 दबाएँ**
→ स्क्रीन पर लाल error आया? हाँ → **हॉटलाइन कॉल करें**
→ भुगतान मोड चुना? नहीं → **F6 दबाकर मोड चुनें**, फिर **F10**
→ कोई लाइन है ही नहीं? → पहले **F3** से दवा खोजकर डालें

**दिक़्क़त २: रसीद नहीं छप रही**
→ प्रिंटर का USB निकला है? → फिर लगाएँ, **F9** दबाएँ
→ प्रिंटर का LED बंद है? → पावर चालू करें
→ कागज़ ख़त्म हो गया? → रोल बदलें, **F9** दोबारा
→ फिर भी नहीं? → **हॉटलाइन कॉल करें** (बिल सेव हो चुका है, घबराइए मत)

**दिक़्क़त ३: ग्राहक UPI दे रहा है पर बिल खाते में जा रहा है**
→ **F6** दबाकर पेमेंट विंडो खोलें
→ Payment mode से **"UPI"** चुनें
→ फिर **F10** से सेव करें

**दिक़्क़त ४: दवा खोज में नहीं मिल रही**
→ वर्तनी सही है? (Crocin, Pantop, Augmentin)
→ अंग्रेज़ी में लिखकर देखें (मराठी/हिंदी में नहीं)
→ बैच नंबर से खोजकर देखें
→ फिर भी नहीं मिले? → **owner को बताएँ**, शायद स्टॉक में नहीं है

**दिक़्क़त ५: कंप्यूटर बीच बिल में हैंग / बंद हो गया**
→ पावर बटन **5 सेकंड** दबाएँ, बंद होने दें
→ फिर चालू करके बूट होने दें
→ लॉगिन करें — बीच का बिल **draft में मिलेगा**
→ **F10** से सेव, **F9** से रसीद। एक भी लाइन नहीं जाती।
