# PharmaCare Pro — कॅशियर कार्ड (मराठी)

*काउंटरवर लॅमिनेट करून चिकटवा. गल्ला सांभाळणाऱ्याला हेच लक्षात ठेवायचंय.*

---

## F-की — एका नजरेत

| की | काय होईल | कधी वापरायची |
|---|---|---|
| **F1** | नवीन बिल / स्क्रीन रिकामी | जुनं बिल संपलं, पुढचं सुरू करायचं |
| **F2** | गिऱ्हाईक निवडा | खातेदार असेल; नाव टाकून Enter |
| **F3** | औषध शोधा | प्रोडक्ट सर्च बॉक्सवर फोकस; नाव लिहा |
| **F4** | सूट टाका | या ओळीवर discount % द्यायची |
| **F6** | पेमेंट विंडो | रोख / UPI / कार्ड निवडायचं |
| **F7** | बॅच बदला | FEFO सोडून दुसरी बॅच हवी |
| **F9** | पावती प्रिंट | बिल सेव झाल्यावर; परत दाबल्यास "Reprint" |
| **F10** | बिल सेव करा | सगळ्या ओळी व पेमेंट आलं |
| **Esc** | विंडो बंद / टोस्ट काढा | पेमेंट विंडो बंद करायची किंवा error काढायचा |
| **Enter** | निवडा / पक्कं करा | ड्रॉपडाउन मधलं औषध किंवा गिऱ्हाईक पक्कं करणं |

> **नियम:** माउसची गरज नाही. पूर्ण बिल कीबोर्डने बनवा — हेच सर्वात वेगवान.

---

## टॉप ५ अडचणी — आणि उत्तरं

**अडचण १: बिल सेव होत नाहीये**
→ F10 दाबला का? नाही → **F10 दाबा**
→ स्क्रीनवर लाल error आला? हो → **हॉटलाइनला कॉल करा**
→ पेमेंट मोड निवडला का? नाही → **F6 ने मोड निवडा**, मग **F10**
→ कुठलीच ओळ नाही? → आधी **F3** ने औषध शोधून टाका

**अडचण २: पावती प्रिंट होत नाहीये**
→ प्रिंटरचा USB निघालाय का? → परत लावा, **F9** दाबा
→ प्रिंटरचा LED बंद आहे? → पॉवर चालू करा
→ कागद संपलाय? → रोल बदला, **F9** परत
→ तरी नाही? → **हॉटलाइनला कॉल करा** (बिल सेव झालंय, घाबरू नका)

**अडचण ३: गिऱ्हाईक UPI देतोय पण बिल खात्यात जातंय**
→ **F6** ने पेमेंट विंडो उघडा
→ Payment mode मधून **"UPI"** निवडा
→ मग **F10** ने सेव्ह करा

**अडचण ४: औषध शोधात मिळत नाहीये**
→ स्पेलिंग बरोबर आहे का? (Crocin, Pantop, Augmentin)
→ इंग्रजीत लिहून बघा (मराठी/हिंदीत नाही)
→ बॅच नंबरने शोधून बघा
→ तरी नाही मिळालं? → **मालकाला सांगा**, कदाचित स्टॉकमध्ये नाही

**अडचण ५: बिलाच्या मध्येच कॉम्प्युटर हँग / बंद झाला**
→ पॉवर बटन **५ सेकंद** दाबा, बंद होऊ द्या
→ मग चालू करून बूट होऊ द्या
→ लॉगिन करा — मधलं बिल **draft मध्ये मिळेल**
→ **F10** ने सेव्ह, **F9** ने पावती. एकही ओळ जात नाही.
