# PharmaCare Pro — દુકાનદાર માટે એક પાનું (ગુજરાતી)

આ કાગળ કાઉન્ટરની પાસે રાખો. રોજનું બધું કામ આ એક પાના ઉપર છે.

---

## ૧) રોજ દુકાન ખોલવી અને બંધ કરવી

**સવારે દુકાન ખોલતી વખતે (૪ સ્ટેપ):**
1. કમ્પ્યૂટર ચાલુ કરો, PharmaCare Pro ખોલો, પોતાનું યૂઝરનેમ અને પાસવર્ડ નાખો.
2. ઉપરના મેનુમાં **"શિફ્ટ"** પર ક્લિક કરો, પછી **"શિફ્ટ ખોલો"** દબાવો.
3. ગલ્લામાં જે રોકડ છે તે ગણીને **"શરૂઆતનો કેશ"** બોક્સમાં નાખો (₹૫૦૦, ₹૨૦૦, ₹૧૦૦, ₹૫૦, ₹૨૦, ₹૧૦, ₹૫, ₹૨, ₹૧, સિક્કા — દરેક ખાનામાં સંખ્યા ભરો). કુલ આપોઆપ બની જશે.
4. **"શિફ્ટ ચાલુ કરો"** બટન દબાવો. લીલો બાર દેખાય તો દુકાન બિલિંગ માટે તૈયાર.

**રાત્રે દુકાન બંધ કરતી વખતે (૪ સ્ટેપ):**
1. છેલ્લું બિલ પૂરું કરીને F1 દબાવો જેથી સ્ક્રીન સાફ થાય.
2. **"શિફ્ટ"** → **"શિફ્ટ બંધ કરો"** પર જાઓ. ગલ્લામાં બાકી રહેલ રોકડ નોટ-સિક્કા ગણીને નાખો.
3. ઍપ **Z-રિપોર્ટ** બતાવશે — કુલ વેચાણ, GST, રોકડ/UPI/કાર્ડ અલગ-અલગ, અને **વેરિયન્સ** (ઍપનો હિસાબ વિરુદ્ધ તમારી ગણતરી). ₹૫૦ સુધીનો ફરક સામાન્ય; વધારે હોય તો આજનું કેશ-બુક ફરી એક વાર જુઓ.
4. **"બંધ કરો અને લોગઆઉટ"** દબાવો. કમ્પ્યૂટર શટ-ડાઉન કરી દો.

---

## ૨) એક બિલ કેવી રીતે બનાવવું — માઉસ વગર

બિલ બનાવતી વખતે માઉસને હાથ લગાડવાની જરૂર નથી. આ ૬ કી યાદ રાખો:

1. **F3** — દવાનું નામ લખો (Crocin, Pantop, Augmentin…). નીચે ડ્રોપડાઉન આવે કે તરત **Enter** દબાવીને પસંદ કરો. પહેલી ઉપલબ્ધ બેચ (FEFO — પહેલા એક્સપાયર થનારી) આપોઆપ લાગી જાય છે.
2. **F2** — ગ્રાહક પસંદ કરો (ખાતું હોય તો). નામ લખીને Enter.
3. **F4** — આ લાઇન પર છૂટ આપવી હોય તો F4 દબાવીને ડિસ્કાઉન્ટ % નાખો.
4. **F7** — FEFO ની જગ્યાએ બીજી બેચ જોઈતી હોય તો F7 થી બેચ-પિકર ખોલો.
5. **F6** — બધી લાઇન થઈ ગઈ તો F6 થી **પેમેન્ટ વિન્ડો** ખોલો. રોકડ / UPI / કાર્ડ પસંદ કરીને Enter અથવા F10.
6. **F9** — રસીદ પ્રિન્ટ થઈ જશે. પછી **F1** થી આગલું બિલ શરૂ.

**માઉસ વગર બધું થઈ જાય છે.** Marg-Tally જેવો જ કીબોર્ડ ફ્લો છે, બસ ઝડપી.

## ૩) રોજનો રિપોર્ટ અને GSTR-1

- **દિવસનું કુલ વેચાણ, જમા થયેલ GST, કેશ વેરિયન્સ** — મેનુ **"ડેશબોર્ડ"** પર એક નજરમાં દેખાઈ જાય.
- **GSTR-1 એક્સપોર્ટ** — મેનુ **"રિપોર્ટ"** → **"GST"** → **"GSTR-1 (માસિક)"**. મહિનો પસંદ કરો, **એક્સપોર્ટ** દબાવો. JSON ફાઇલ ડેસ્કટોપ પર બને છે — CA ને મોકલો અથવા જાતે GST પોર્ટલ પર અપલોડ કરો.
- **ખાતું / લેજર** — **"ડિરેક્ટરી"** → ગ્રાહકનું નામ → **"લેજર જુઓ"**. ઉધાર-વસૂલી, જૂના બિલ, બાકી રકમ બધું ત્યાં જ.
- **Schedule H/H1/X રજિસ્ટર** — **"કમ્પ્લાયન્સ"** ટૅબમાં આપોઆપ ભરાય. ડ્રગ ઇન્સ્પેક્ટર માગે તો PDF એક્સપોર્ટ કરી દો.

## ૪) જો વીજળી જતી રહે

ગભરાશો નહીં. ઍપ દર **૨ સેકન્ડે** તમારું બિલ લોકલ SQLite ડેટાબેઝમાં સેવ કરતી રહે છે (Tauri ઑટો-સેવ).

1. વીજળી પાછી આવે ત્યારે કમ્પ્યૂટર ચાલુ કરો, PharmaCare Pro ફરી ખોલો.
2. લોગિન કરો — ઍપ એ જ ડ્રાફ્ટ બિલ બતાવશે જે વચ્ચે હતું. **એક પણ લાઇન જતી નથી.**
3. F10 દબાવીને બિલ સેવ કરો, પછી F9 થી રસીદ પ્રિન્ટ કરી દો.
4. જો વીજળી જાય તે પહેલા રસીદ છપાયેલી ન હોય — બિલ સેવ થયા પછી **F9 ફરી દબાવો**, "Reprint" સ્ટેમ્પ સાથે રસીદ આવી જશે.

## ૫) જો ઇન્ટરનેટ ન હોય

PharmaCare Pro **LAN-first** છે એટલે કે **ઇન્ટરનેટ વગર પણ ૧૦૦% કામ કરે છે**. દુકાનનું રોજનું બિલ, સ્ટોક, ખાતું, GST રજિસ્ટર — બધું તમારા જ કમ્પ્યૂટર પર લોકલ ચાલે છે.

- **GSTR-1 એક્સપોર્ટ** — JSON ફાઇલ ડિસ્ક પર બની જાય; જ્યારે નેટ આવે ત્યારે અપલોડ કરી દો.
- **Schedule H/H1/X, ડ્રગ રજિસ્ટર, બેચ-એક્સપાયરી ટ્રેકિંગ** — બધું લોકલ. નેટ સાથે કોઈ સંબંધ નહીં.
- **ABDM / ABHA** જેવી ઑનલાઇન સુવિધાઓ ત્યારે જ ચાલે જ્યારે નેટ હોય; ન હોય તો બાકી બધું ચાલુ રહે છે.
- **પાક્કું કરવું હોય ત્યારે** ("મારે પાક્કું કરવું છે કે આ બરાબર ગયું કે નહીં") — હૉટલાઇન પર કૉલ કરો (નીચે).
