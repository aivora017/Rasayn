# PharmaCare Pro — दुकानदारासाठी एक पान (मराठी)

हा कागद काउंटरजवळ ठेवा. रोजचं काम याच एका पानावर आहे.

---

## १) रोज दुकान उघडणं आणि बंद करणं

**सकाळी दुकान उघडताना (४ पायऱ्या):**
1. कॉम्प्युटर चालू करा, PharmaCare Pro उघडा, स्वतःचं युझरनेम आणि पासवर्ड टाका.
2. वरच्या मेन्यूत **"शिफ्ट"** वर क्लिक करा, मग **"शिफ्ट उघडा"** दाबा.
3. गल्ल्यातली रोख रक्कम मोजून **"सुरुवातीचा कॅश"** बॉक्समध्ये भरा (₹५००, ₹२००, ₹१००, ₹५०, ₹२०, ₹१०, ₹५, ₹२, ₹१, नाणी — प्रत्येक कप्प्यात संख्या टाका). एकूण आपोआप जुळेल.
4. **"शिफ्ट चालू करा"** बटण दाबा. हिरवा बार दिसला की दुकान बिलिंगसाठी तयार.

**रात्री दुकान बंद करताना (४ पायऱ्या):**
1. शेवटचं बिल पूर्ण करून F1 दाबा म्हणजे स्क्रीन रिकामी होईल.
2. **"शिफ्ट"** → **"शिफ्ट बंद करा"** वर जा. गल्ल्यात उरलेली रोख नोटा-नाणी मोजून टाका.
3. ॲप **Z-रिपोर्ट** दाखवेल — एकूण विक्री, GST, रोख/UPI/कार्ड वेगवेगळं, आणि **व्हेरियन्स** (ॲपचा हिशोब विरुद्ध तुमची मोजणी). ₹५० पर्यंतचा फरक सामान्य; जास्त असेल तर आजचं कॅश-बुक एकदा परत बघा.
4. **"बंद करा आणि लॉगआउट"** दाबा. कॉम्प्युटर शट-डाउन करा.

---

## २) एक बिल कसं बनवायचं — माउसशिवाय

बिल बनवताना माउसला हात लावायची गरज नाही. या ६ की लक्षात ठेवा:

1. **F3** — औषधाचं नाव लिहा (Crocin, Pantop, Augmentin…). खाली ड्रॉपडाउन आला की **Enter** दाबून निवडा. पहिली उपलब्ध बॅच (FEFO — आधी एक्सपायर होणारी) आपोआप लागते.
2. **F2** — गिऱ्हाईक निवडा (खातं असेल तर). नाव टाकून Enter.
3. **F4** — या ओळीवर सूट द्यायची असेल तर F4 दाबून डिस्काउंट % टाका.
4. **F7** — FEFO सोडून दुसरी बॅच हवी असेल तर F7 ने बॅच-पिकर उघडा.
5. **F6** — सगळ्या ओळी झाल्या की F6 ने **पेमेंट विंडो** उघडा. रोख / UPI / कार्ड निवडून Enter किंवा F10.
6. **F9** — पावती प्रिंट होईल. मग **F1** ने पुढचं बिल सुरू.

**माउसशिवाय सगळं होतं.** Marg-Tally सारखाच कीबोर्ड फ्लो, फक्त वेगवान.

## ३) रोजचा रिपोर्ट आणि GSTR-1

- **दिवसाची एकूण विक्री, जमा झालेला GST, कॅश व्हेरियन्स** — मेन्यू **"डॅशबोर्ड"** वर एका नजरेत दिसतं.
- **GSTR-1 एक्सपोर्ट** — मेन्यू **"रिपोर्ट"** → **"GST"** → **"GSTR-1 (मासिक)"**. महिना निवडा, **एक्सपोर्ट** दाबा. JSON फाइल डेस्कटॉपवर बनते — CA ला पाठवा किंवा स्वतः GST पोर्टलवर अपलोड करा.
- **खातं / लेजर** — **"डायरेक्टरी"** → गिऱ्हाईकाचं नाव → **"लेजर बघा"**. उधारी, जुनी बिलं, बाकी रक्कम सगळं तिथेच.
- **Schedule H/H1/X रजिस्टर** — **"कम्प्लायन्स"** टॅबमध्ये आपोआप भरतं. ड्रग इन्स्पेक्टरने मागितलं तर PDF एक्सपोर्ट करा.

## ४) वीज गेली तर

घाबरू नका. ॲप दर **२ सेकंदाला** तुमचं बिल लोकल SQLite डेटाबेसमध्ये सेव्ह करत राहतं (Tauri ऑटो-सेव्ह).

1. वीज परत आल्यावर कॉम्प्युटर चालू करा, PharmaCare Pro परत उघडा.
2. लॉगिन करा — ॲप तोच ड्राफ्ट बिल दाखवेल जो मध्ये होता. **एकही ओळ जात नाही.**
3. F10 दाबून बिल सेव्ह करा, मग F9 ने पावती प्रिंट करा.
4. वीज गेल्यावर पावती छापली नसेल तर — बिल सेव्ह झाल्यावर **F9 परत दाबा**, "Reprint" शिक्क्यासह पावती मिळेल.

## ५) इंटरनेट नसेल तर

PharmaCare Pro **LAN-first** आहे म्हणजे **इंटरनेटशिवायही १००% चालतं**. दुकानाचं रोजचं बिल, स्टॉक, खातं, GST रजिस्टर — सगळं तुमच्याच कॉम्प्युटरवर लोकल चालतं.

- **GSTR-1 एक्सपोर्ट** — JSON फाइल डिस्कवर तयार होते; जेव्हा नेट येईल तेव्हा अपलोड करा.
- **Schedule H/H1/X, ड्रग रजिस्टर, बॅच-एक्सपायरी ट्रॅकिंग** — सगळं लोकल. नेटशी काही संबंध नाही.
- **ABDM / ABHA** सारखी ऑनलाइन फीचर्स फक्त नेट असेल तरच चालतात; नसेल तर बाकी सगळं चालू राहतं.
- **पक्कं करायचं असेल तर** ("मला पक्कं करायचंय हे बरोबर गेलंय की नाही") — हॉटलाइनवर कॉल करा (खाली).
