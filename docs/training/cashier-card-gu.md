# PharmaCare Pro — કેશિયર કાર્ડ (ગુજરાતી)

*કાઉન્ટર પર લેમિનેટ કરીને ચોંટાડો. ગલ્લો સંભાળનારે આટલું જ યાદ રાખવાનું છે.*

---

## F-કી — એક નજરમાં

| કી | શું થશે | ક્યારે વાપરવી |
|---|---|---|
| **F1** | નવું બિલ / સ્ક્રીન સાફ | જૂનું બિલ પૂરું, આગલું શરૂ કરવું છે |
| **F2** | ગ્રાહક પસંદ કરો | ખાતેદાર હોય; નામ લખીને Enter |
| **F3** | દવા શોધો | પ્રોડક્ટ સર્ચ બોક્સ પર ફોકસ; નામ લખો |
| **F4** | છૂટ નાખો | આ લાઇન પર discount % આપવો છે |
| **F6** | પેમેન્ટ વિન્ડો | રોકડ / UPI / કાર્ડ પસંદ કરવું |
| **F7** | બેચ બદલો | FEFO ની જગ્યાએ બીજી બેચ જોઈએ |
| **F9** | રસીદ પ્રિન્ટ | બિલ સેવ થયા પછી; ફરી દબાવો તો "Reprint" |
| **F10** | બિલ સેવ કરો | બધી લાઇન અને પેમેન્ટ આવી ગયું |
| **Esc** | વિન્ડો બંધ / ટોસ્ટ કાઢો | પેમેન્ટ વિન્ડો બંધ કરવી હોય કે error કાઢવી |
| **Enter** | પસંદ કરો / પાક્કું કરો | ડ્રોપડાઉનમાંથી દવા કે ગ્રાહક પાક્કું કરવું |

> **નિયમ:** માઉસની જરૂર નથી. આખું બિલ કીબોર્ડથી જ બનાવો — એ જ સૌથી ઝડપી.

---

## ટોચની ૫ તકલીફો — અને તેનો ઉપાય

**તકલીફ ૧: બિલ સેવ થતું નથી**
→ F10 દબાવ્યું? ના → **F10 દબાવો**
→ સ્ક્રીન પર લાલ error આવ્યો? હા → **હૉટલાઇન કૉલ કરો**
→ પેમેન્ટ મોડ પસંદ કર્યો? ના → **F6 થી મોડ પસંદ કરો**, પછી **F10**
→ કોઈ લાઇન જ નથી? → પહેલા **F3** થી દવા શોધીને નાખો

**તકલીફ ૨: રસીદ પ્રિન્ટ થતી નથી**
→ પ્રિન્ટરનું USB નીકળી ગયું છે? → ફરી લગાવો, **F9** દબાવો
→ પ્રિન્ટરનું LED બંધ છે? → પાવર ચાલુ કરો
→ કાગળ પૂરો થઈ ગયો? → રોલ બદલો, **F9** ફરી
→ તો પણ નહીં? → **હૉટલાઇન કૉલ કરો** (બિલ સેવ થઈ ગયું છે, ગભરાશો નહીં)

**તકલીફ ૩: ગ્રાહક UPI આપે છે પણ બિલ ખાતામાં જઈ રહ્યું છે**
→ **F6** થી પેમેન્ટ વિન્ડો ખોલો
→ Payment mode માંથી **"UPI"** પસંદ કરો
→ પછી **F10** થી સેવ કરો

**તકલીફ ૪: દવા શોધવામાં મળતી નથી**
→ સ્પેલિંગ સાચું છે? (Crocin, Pantop, Augmentin)
→ અંગ્રેજીમાં લખીને જુઓ (ગુજરાતી/હિંદીમાં નહીં)
→ બેચ નંબરથી શોધીને જુઓ
→ તો પણ નહીં મળે? → **માલિકને કહો**, કદાચ સ્ટોકમાં નથી

**તકલીફ ૫: બિલની વચ્ચે કમ્પ્યૂટર હેન્ગ / બંધ થઈ ગયું**
→ પાવર બટન **૫ સેકન્ડ** દબાવો, બંધ થવા દો
→ પછી ચાલુ કરીને બૂટ થવા દો
→ લોગિન કરો — વચ્ચેનું બિલ **draft માં મળશે**
→ **F10** થી સેવ, **F9** થી રસીદ. એક પણ લાઇન જતી નથી.
